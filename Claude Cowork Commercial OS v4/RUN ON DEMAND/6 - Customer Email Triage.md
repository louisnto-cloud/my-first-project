# Customer Email Triage

- **Best used when:** an email thread is messy and you need the signal and the next move
- **Best used in:** Cowork project
- **Recommended skills:** Commercial Meeting Extractor, Follow-Up Drafter
- **Why this exists:** It turns a long or tangled thread into asks, commitments, risks, and a clean draft reply.

> Authored to the system's spec. The Operator Guide names this prompt but does not include its body; this version follows the guide's conventions. Tune to taste.

## Paste into Claude:

Triage this email thread: [Paste or point to the thread].
Work inside this project and cross-check against the current approved files in the File Index.

Extract:

1. What the customer or stakeholder is actually asking for
2. What we have committed to, explicitly or implicitly
3. Open questions that need an answer
4. Decisions that have been made in the thread
5. Risks, timing pressure, or credibility issues
6. What belongs in the Control Tower (asks, actions, decisions, risks)

Then:

1. Give me a short summary of where the thread stands
2. List the actions with suggested owner and due date (do not invent — flag if unknown)
3. Draft a professional, concise reply I can review and edit
4. Flag anything sensitive that should not be sent without checking

Important:

- separate what was actually said from what is inferred
- do not send the reply — draft only
- do not over-commit on my behalf; keep the draft to what is supportable
- note which Control Tower tabs should be updated

Save as:
`YYYY-MM-DD - [Project] - Email Triage - [Topic]`
