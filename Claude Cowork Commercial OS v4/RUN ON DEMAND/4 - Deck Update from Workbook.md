# Deck Update from Workbook

- **Best used when:** the commercial story has moved and the deck is behind
- **Best used in:** Cowork project (or cross-app when both files are open)
- **Recommended skills:** Deck Story Builder, Open Loop Manager
- **Why this exists:** It turns the Deck Backlog and tracker movement into concrete, reviewable slide changes.

> Authored to the system's spec. The Operator Guide names this prompt but does not include its body; this version follows the guide's conventions. Tune to taste.

## Paste into Claude:

Update the deck story for this project from the workbook.
Use the current approved deck and the current approved Control Tower workbook from the File Index.

Review:

- the Deck Backlog tab
- recent decisions, risks, customer asks, and forecast or launch changes
- what materially changed since the deck was last updated

For each slide or section that is now out of date, tell me:

1. What the slide currently says
2. What changed in the commercial reality
3. The recommended new message or data point
4. Why it matters (sales, margin, timing, retailer, or risk)
5. The confidence level and any evidence gap

Then produce:

1. A prioritized list of slide changes (P0 / P1 / nice-to-have)
2. Draft replacement language for the top changes
3. Any new slide that the story now needs
4. Slides that can be cut or simplified

Important:

- do not edit the approved master deck — produce a review copy or a change list
- separate confirmed changes from assumptions
- do not invent numbers; flag where a current figure is needed

Save as:
`YYYY-MM-DD - [Project] - Deck Update Recommendations`
and if a review copy is built:
`REVIEW - YYYY-MM-DD - [Project] - Deck`
