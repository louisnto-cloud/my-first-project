# Executive Decision Memo

- **Best used when:** a decision needs a clear, one-page answer
- **Best used in:** Cowork project
- **Recommended skills:** Open Loop Manager, Daily Brief Builder
- **Why this exists:** It forces a messy situation into a single, senior-ready recommendation.

> Authored to the system's spec. The Operator Guide names this prompt but does not include its body; this version follows the guide's conventions. Tune to taste.

## Paste into Claude:

Write a one-page executive decision memo on: [The decision to be made].
Work inside this project and use the current approved files from the File Index.

Pull the relevant context: meetings, decisions, risks, customer asks, forecast or launch impact, and anything that changed recently.

Structure the memo as:

1. The decision (one sentence)
2. Why it matters now and what is at stake commercially
3. The options, with a brief upside, downside, and risk for each
4. The recommended option, first and clearly
5. What it depends on (assumptions, owners, timing)
6. What happens if we do nothing
7. The next action, owner, and by-when

Important:

- recommend the best option first
- keep it to one page, decision-ready
- distinguish confirmed facts, inferred points, and assumptions
- do not invent numbers, owners, or commitments; flag what is missing
- do not send anything externally

Save as:
`YYYY-MM-DD - [Project] - Decision Memo - [Topic]`
