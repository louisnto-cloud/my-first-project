# New Workflow Prompt Builder

- **Best used when:** you want Claude to help you design a new Cowork routine
- **Recommended skills:** Prompt Builder
- **Why this exists:** It gives you a repeatable way to create good prompts without writing them from scratch.

## Paste into Claude:

Act as my Cowork workflow designer.

I want to create a new workflow for: [Describe the job].

Build me:

1. the best project-safe prompt for this job,
2. the best skill description if this should become a skill,
3. the best schedule recommendation if this should recur,
4. the correct write mode:
   - read-only diagnostic
   - draft-only output
   - review-copy update
   - explicit overwrite only
5. the right success criteria for the workflow

Optimize for:

- commercial usefulness
- trust
- low ambiguity
- low duplicate work
- strong handoff into my Control Tower, deck backlog, or follow-up

Make grounded assumptions and keep the result ready to paste into Cowork.
