# Folder Instructions

Use this as the folder instructions file in the local working folder.

---

This folder is a working commercial system for one project.
Treat it as an operating workspace, not a storage dump.

Folder goals:

- keep active files easy to find
- preserve source-of-truth files
- make review copies easy to distinguish from approved files
- keep meeting intake clean
- make tracker and deck handoffs obvious

Preferred folder logic:

- `/01 Inbox` = new or unprocessed items
- `/02 Control Tower` = workbook, queue, deltas
- `/03 Meetings` = meeting notes, transcripts, summaries
- `/04 Decks` = approved decks and review copies
- `/05 Workbooks` = sales, forecast, pricing, launch files
- `/06 Briefs and Reviews` = daily briefs, weekly pulses, decision memos
- `/07 Reference` = supporting material worth keeping

Working rules:

- do not move or rename important files unless there is a clear benefit
- do not create duplicate files unless a review copy is needed
- if the current approved file is unclear, update the File Index first
- keep file names human-readable
- when new meeting material appears, place it in the meeting workflow instead of leaving it loose in the inbox

Naming rules:

- approved source file names should stay stable
- review copies should begin with `REVIEW -`
- deltas should begin with `DELTA -`
- generated summaries and briefs should use:
  `YYYY-MM-DD - [Project] - [Output Type]`

If the folder is messy, improve it carefully and preserve traceability.
