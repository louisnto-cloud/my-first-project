# Retailer and Competitor Watch

- **Suggested cadence:** Weekly (Full Mode only)
- **Best used in:** Cowork project
- **Recommended skills:** Commercial Meeting Extractor, Open Loop Manager
- **Why this exists:** It turns scattered retailer and competitor signal into a short, decision-ready digest so nothing material is missed.

> Full-Mode / optional. Listed under Full Mode in the guide ("retailer and competitor watch"). Authored to the system's spec. Only add after the core loop is stable, and keep the source list tight — this is where noise creeps in fastest.

## Paste into a scheduled task:

Build the retailer and competitor watch digest for this project.
Use only the sources connected to this project and the current approved files in the File Index.

Review the last 7 days for signal on:

- retailer moves — assortment, promo, pricing, reset timing, service or supply changes
- competitor moves — new items, distribution gains, promo mechanics, pack or price changes
- category shifts that affect our story
- anything that changes a commitment, a risk, or the deck narrative

For each meaningful signal, tell me:

1. What happened (with the source)
2. Whether it is confirmed, inferred, or rumor
3. Why it matters to us commercially (sales, margin, timing, retailer, risk)
4. What action, if any, it triggers — and whether it belongs in the Control Tower

Then give me:

- a one-page watch digest, most consequential first
- new items to log as risks, asks, or actions
- anything that should change the deck story
- what only deserves monitoring for now

Important:

- separate signal from noise — omit low-value chatter
- do not present rumor as fact
- do not invent numbers or sources
- do not send anything externally

Save as:
`YYYY-MM-DD - [Project] - Retailer and Competitor Watch`
