# Worked Examples

These are **illustrative, fully fictional** sample outputs — a fabricated brand ("Acme Naturals") in a fabricated Costco scenario — so you can see the *shape* of a good result before you run the system on real data. They are templates of quality, not records of anything.

Nothing here is real. No numbers, people, commitments, or events in these files are genuine. Do not treat them as source of truth and do not paste them into a real account project.

| File | Produced by | Shows |
|---|---|---|
| `Sample - Daily Brief.md` | `SCHEDULE THESE/1 - Daily Commercial Brief.md` | A ready-in-5-minutes morning brief with meeting-by-meeting prep |
| `Sample - Meeting Summary.md` | `SCHEDULE THESE/2 - Meeting Inbox Processor.md` + Commercial Meeting Extractor | Clean signal extraction with Control Tower handoff |
| `Sample - Friday Pulse.md` | `SCHEDULE THESE/3 - Friday Account Pulse.md` | Weekly movement and consequence, not restatement |
| `Sample - Decision Memo.md` | `RUN ON DEMAND/5 - Executive Decision Memo.md` | A one-page, recommendation-first decision memo |
| `Sample - Bootstrap Memo.md` | `SETUP TASKS/1 - Account Bootstrap.md` | The first usable context layer for a new project |

Use these to calibrate: if your real outputs are longer, softer, or less action-oriented than these, tune the prompt or the extraction rule — don't add more automation.
