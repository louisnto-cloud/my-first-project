# Account Bootstrap

Use this once when you first stand up a project.

- **Best used in:** Cowork project
- **Recommended skills:** Open Loop Manager, Daily Brief Builder
- **Why this exists:** It gives the project a usable starting context so later scheduled tasks are not working from zero.

## Paste into Claude:

Bootstrap this project into a usable commercial operating system.
Work only inside this project and its connected context.

Your job:

1. Identify the current approved deck, current working deck, key workbooks, and the correct Control Tower workbook.
2. Update or create the File Index so the current approved files are clearly marked.
3. Review the most recent 30 days of relevant meetings, notes, decks, workbooks, email context, and linked files.
4. Build an initial open-loops view:
   - open actions
   - open customer asks
   - open risks
   - open deck backlog items
   - unresolved decisions
5. Create a concise bootstrap memo that tells me:
   - what this project is about
   - what is currently live
   - what is blocked
   - what needs my attention first
   - what files are source of truth
6. If the Control Tower workbook is present, update it in review-copy mode or create a delta file.
7. If the project folder is messy, improve organization carefully without breaking traceability.

Output:

1. Project snapshot
2. Current approved files
3. Open loops
4. Risks and blockers
5. Recommended next moves
6. Files that should be cleaned up or renamed

Important:

- do not overwrite master files
- do not invent owners or due dates
- do not send messages

Save as:
`YYYY-MM-DD - [Project] - Bootstrap Memo`

and if needed:
`DELTA - YYYY-MM-DD - [Project] - Control Tower`
