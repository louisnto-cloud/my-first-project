# Claude Cowork Commercial OS v4 — Operator Pack

Built for user-friendliness, faster setup, stronger follow-through, and cleaner commercial decision support.

**Best starting point:** Costco pilot first, then FDM once the first week is stable.

This pack is built for real operating use, not demo use. It is designed for three things:

1. making your meetings more useful,
2. making follow-through visible, and
3. making deck and decision updates happen faster.

---

## How to read this pack

Start with:

- `00 START HERE - 30 Minute Setup.md`
- `01 WHY THIS SYSTEM IS BUILT THIS WAY.md`
- `COPY INTO CLAUDE/Global Instructions.md`
- `COPY INTO CLAUDE/Project Instructions - Generic.md`
- `SCHEDULE THESE/1 - Daily Commercial Brief.md`
- `SCHEDULE THESE/2 - Meeting Inbox Processor.md`
- `SCHEDULE THESE/3 - Friday Account Pulse.md`

If you want the fastest pilot, use Costco first, then copy the same model into FDM once the first week feels stable.

## What's in this pack

| Folder / File | What it is |

| `RUN ON DEMAND/` | One-off prompts for meeting prep, tracker refresh, deck updates, decision memos, email triage, source-of-truth refresh, and a new-workflow builder. |
| `SKILLS - READY TO UPLOAD/` | The five narrow core skills: Commercial Meeting Extractor, Open Loop Manager, Daily Brief Builder, Deck Story Builder, Follow-Up Drafter. |

## Provenance note (please read)

This pack was scaffolded from the **Claude Cowork Commercial OS v4 — Operator Guide**.

- **Verbatim from the guide:** the `COPY INTO CLAUDE/` instruction stack and account overlays, the `SETUP TASKS/`, the three `SCHEDULE THESE/` tasks, `RUN ON DEMAND/10 - New Workflow Prompt Builder.md`, and all of the `GUIDE/` reference docs.
- **Authored to the guide's spec (not verbatim):** the five `SKILLS - READY TO UPLOAD/` SKILL.md files, and the `RUN ON DEMAND/` prompts numbered 1, 3, 4, 5, 6, and 9. The guide names these and describes their jobs but does not include their full body text, so they were written here in the system's style and conventions. Review them before relying on them, and tune to taste.

The guide's quick-reference numbering skips 2, 7, and 8 in `RUN ON DEMAND/`; those were not referenced anywhere in the source guide, so they are intentionally absent.
