# How to Use This Every Week

The easiest way to think about the system is by rhythm.

## Every morning

Read the Daily Commercial Brief.
Use it to answer five questions before your day starts:

- What matters today?
- What changed?
- What is due soon?
- What risk is live?
- What file should I open before the meeting?

You should be able to read this in under five minutes.

## After meetings

Drop the transcript, notes, agenda, or deck into the project folder if it is not already there.
Then run the Meeting Inbox Processor, or let the scheduled version pick it up later.

Its job is to do three things:

- extract the signal,
- update the Control Tower,
- and draft the follow-up.

If it does not do at least two of those three, the workflow needs tuning.

## On Fridays

Read the Friday Account Pulse.
This is not just a summary.
It should tell you:

- what moved this week,
- what slipped,
- what is now the real priority next week,
- and what the deck story likely needs.

## On Mondays

Run the Open Loops review if your workload is heavy.
This is useful when too many actions are drifting, too many items lack owners, or too many "waiting" items never come back.

## Monthly

Use Monthly Business Review Prep to force the system to connect:

- actions,
- decisions,
- risks,
- retailer asks,
- launches,
- forecast shifts,
- deck updates.

That turns the weekly activity into executive-ready narrative.

## The day-to-day rule

- Use Cowork for cross-file work and long-running workflows.
- Use Claude for Excel when the workbook is already open and you want analysis or updates inside the file.
- Use Claude for PowerPoint when the deck is already open and you want direct slide work.
- Use cross-app workflows when both files are open and the task truly crosses from data to story.

That split keeps the toolchain clean.
