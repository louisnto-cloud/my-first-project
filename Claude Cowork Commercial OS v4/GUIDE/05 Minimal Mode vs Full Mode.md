# Minimal Mode vs Full Mode

This pack is designed to work in two modes.

## Minimal mode

Use this first.
It includes:

- one project
- one workbook
- five core skills
- three scheduled tasks

Minimal mode is enough for most people to prove whether the system works.

## Full mode

Only move here after the first week is stable.
Add:

- optional skills
- optional scheduled scans
- retailer and competitor watch
- launch and forecast checks
- monthly prep workflows
- second and third projects

## Why this split exists

Most systems fail because they start in full mode.
The user then spends more time maintaining the system than benefiting from it.
This design forces the system to earn complexity.
