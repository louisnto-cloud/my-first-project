# Quick Reference: Which Prompt to Use

Use this when you know the job but not the right prompt.

- If you need **meeting prep**, use `RUN ON DEMAND/1 - Meeting Prep Note.md`.
- If you need **post-meeting extraction**, use `SCHEDULE THESE/2 - Meeting Inbox Processor.md` or the Meeting Extractor skill.
- If the **tracker feels stale**, use `RUN ON DEMAND/3 - Action Tracker Refresh.md`.
- If the **deck feels stale**, use `RUN ON DEMAND/4 - Deck Update from Workbook.md`.
- If a **decision needs a one-page answer**, use `RUN ON DEMAND/5 - Executive Decision Memo.md`.
- If an **email thread is messy**, use `RUN ON DEMAND/6 - Customer Email Triage.md`.
- If Claude keeps **using the wrong files**, use `RUN ON DEMAND/9 - Source of Truth Refresh.md`.
- If you want a **brand-new workflow**, use `RUN ON DEMAND/10 - New Workflow Prompt Builder.md`.
