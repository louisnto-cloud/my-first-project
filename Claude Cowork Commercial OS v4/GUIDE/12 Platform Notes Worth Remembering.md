# Notes Worth Remembering

This pack was designed around a few current Cowork realities.

- Projects have their own instructions, context, memory, and scheduled tasks.
- Folder instructions add local context and can be updated by Claude during a session.
- Scheduled tasks only run while Claude Desktop is open and the computer is awake.
- Skills work best when they solve one specific repeatable task.
- Connectors inherit your permissions from the source system.
- Microsoft 365 connection may require organization enablement and Entra admin consent.
- Excel and PowerPoint cross-app workflows only work on files that are currently open.
- Plugins can expand Claude's scope materially, so install them carefully.
- Cowork activity is not currently captured in audit logs, the Compliance API, or data exports.

Use those realities to decide what to automate and what to review.
