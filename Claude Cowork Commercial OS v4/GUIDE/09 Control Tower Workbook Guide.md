# Control Tower Workbook Guide

This workbook is the operational landing zone for the system.

Use one workbook per project.
That means:

- one Costco workbook,
- one FDM workbook,
- one Sales Ops workbook.

## Why that is better

- It reduces clutter.
- It keeps file ownership clear.
- It makes the workbook usable by a human.
- It aligns naturally with Cowork project memory.

## What each tab is for

### Dashboard
Your fast status read.

### Action Tracker
The accountability layer.

### Decision Log
Important decisions that should not be buried in notes.

### Risk Register
Live risks, severity, mitigation, and ownership.

### Customer Asks
What the retailer or stakeholder asked for and what needs to happen internally.

### Deck Backlog
What the current deck needs to change.

### Meeting Queue
What has come in and whether it has been processed.

### File Index
Which file is the real source of truth.

## How Claude should use it

Claude should update it in review-copy mode by default.
If direct edit is not appropriate, Claude should create a delta file.

## The rule that matters

> No summary is finished until the parts that matter have landed here.
