# Costco Pilot: First 7 Days

- Day 1 is setup.
- Days 2 to 5 are observation.
- Day 6 is tuning.
- Day 7 is decision.

## Day 1

- Set up the Costco project.
- Install the core skills.
- Add the Control Tower workbook.
- Run Account Bootstrap and Historical Backfill.
- Turn on the three core scheduled tasks.

## Days 2 to 5

Do not add more automation.
Just use the system.

Pay attention to:

- whether the Daily Brief is genuinely helpful,
- whether actions are landing in the tracker,
- whether new deck work is being surfaced,
- whether follow-up drafts save real time.

## Day 6

Tune only what is clearly broken.

Examples:

- If the brief is too long, ask for one page and P0/P1 only.
- If the meeting processor misses actions, strengthen the action extraction rule.
- If the wrong files are being used, clean the File Index.

## Day 7

Make the go or no-go decision.

If the system is buying back time and improving clarity, clone it into FDM.
If not, simplify it before expanding.
