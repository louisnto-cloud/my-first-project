# Connectors, Plugins, and Surfaces

Use the cleanest path first.

## Start with connectors

If you work in Microsoft 365, start there.
That usually gives the biggest lift because it puts email, calendar, chats, files, and shared documents into the same working context.

If Slack is where real internal decisions happen, add Slack after Microsoft 365.

The main point is not to connect everything.
It is to connect the sources that contain the real signal.

## Be careful with plugins

Plugins can be powerful, but they expand what Claude can do.
Only add a plugin when it gives you something the core system genuinely needs.
Do not install them just because they exist.

## Use the right surface for the job

### Cowork project
Use this for:

- multi-file work
- long-running workflows
- meeting inbox processing
- scheduled tasks
- weekly or monthly synthesis

### Claude for Excel
Use this when the workbook is already open and you want:

- analysis
- cleanup
- formula-aware outputs
- workbook edits

### Claude for PowerPoint
Use this when the deck is already open and you want:

- slide editing
- structure changes
- wording changes
- narrative cleanup

### Cross-app work
Use this only when:

- both the workbook and deck are open
- the task genuinely moves from numbers to story
- you want direct file updates

If the job is mainly thinking, stay in Cowork.
If the job is mainly editing a live file, use the add-in.
