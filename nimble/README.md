# Nimble — rapid-response communication trainer

A small local web app that drills you on thinking fast under conversational pressure. Claude generates a scenario that ends with someone putting you on the spot; you get 10–30 seconds to type your reply; Claude judges it 1–10 with feedback.

## Setup

```sh
cd nimble
npm install
cp .env.example .env   # then add your ANTHROPIC_API_KEY
npm start              # http://localhost:3000
```

## How it works

- **Time limit** — chosen once (10/15/20/30s), remembered in `data/store.json`.
- **Domains** — rotates through business & sales negotiation, legal/debate argument, and high-stakes personal confrontation in shuffled blocks: no domain repeats before the other two have appeared.
- **Scenarios** — generated by `claude-sonnet-4-6` (3–5 sentences, ending at a moment of pressure with a direct question), scaled by difficulty.
- **Difficulty** — starts at level 1, +1 every 5 drills, capped at 5. Higher levels are more emotionally loaded and harder to read.
- **Judging** — on submit (or auto-submit at timeout), Claude scores the reply 1–10 and returns short feedback.
- **Tracking** — every drill (domain, scenario, response, score, feedback, timestamp, timed-out flag) is logged to `data/store.json`. The stats view shows total drills, overall and per-domain averages, and a score-over-time line chart.

## Layout

```
nimble/
  server.js        Express server + API routes
  lib/claude.js    Claude API calls (scenario generator + judge prompts)
  lib/store.js     JSON-file persistence, domain rotation, difficulty, stats
  public/          Frontend (vanilla HTML/CSS/JS, dark theme)
  data/store.json  Local state (gitignored)
```
